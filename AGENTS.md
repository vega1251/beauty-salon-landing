# Правила работы Codex

Перед изменениями прочитай [ТЗ](PROJECT_SPEC.md), [дизайн-систему](DESIGN_SYSTEM.md), [правовые требования](LEGAL_REQUIREMENTS.md), [текущее состояние](CURRENT_STATE.md) и [README](README.md). Учитывай существующие изменения. При существенном конфликте требований уточни его, продолжая независимую работу.

- Используй семантический HTML, CSS с переменными и ванильный JavaScript. Сохраняй доступ к основному контенту без JS. Пути к ресурсам относительные, с учётом подпапки GitHub Pages.
- Используй локальные ресурсы с подтверждёнными правами. Фиксируй источник, лицензию и атрибуцию. При отсутствии прав используй собственные нейтральные заглушки.
- Сохраняй режим вымышленного салона. Не добавляй формы, запись, оплату, поля ввода, трекеры, cookies, клиентские хранилища, внешние виджеты или загрузки. Изменение режима требует решения владельца и повторной правовой проверки.
- Не подключай сборщики, фреймворки, сервер, CMS или платные зависимости без согласования. Не добавляй реальные контакты, отзывы и реквизиты в демо.
- Проверяй изменения по критериям ТЗ. Обновляй CURRENT_STATE.md и CHANGELOG.md по фактическим результатам. Перечисляй проверки, которые не удалось выполнить.
- Push, включение Pages, публикация и передача материалов вовне требуют явного разрешения владельца.
